# Читалка

Личная читалка книг с Google Диска: категории-папки, маркер, перо, комментарии, заметки и теги.
Работает в браузере телефона и планшета, ставится на экран как приложение, скачанные книги открываются без интернета.

Форматы: EPUB, PDF, FB2 (и FB2.ZIP), TXT, DOCX, MOBI, AZW3 (без защиты DRM), CBZ (комиксы).

## 1. Разместить приложение на GitHub Pages (бесплатно)

1. Зарегистрируйтесь на github.com (если ещё нет аккаунта).
2. Нажмите «+» вверху справа → **New repository**. Название: `reader`. Тип: **Public**. Нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file** (или **Add file → Upload files**).
4. Распакуйте архив на компьютере и перетащите в окно браузера **всё содержимое** папки `reader` (файл `index.html` должен оказаться в корне, а не внутри вложенной папки). Нажмите **Commit changes**.
5. Откройте **Settings → Pages**. В **Source** выберите **Deploy from a branch**, ветку **main**, папку **/ (root)** → **Save**.
6. Через 1–2 минуты появится адрес вида `https://ВАШ-ЛОГИН.github.io/reader/`. Это адрес вашей читалки.

Код приложения будет публичным, но ваши книги и заметки — нет: они лежат на вашем Google Диске.

## 2. Получить ключ Google (Client ID)

1. Откройте console.cloud.google.com и войдите тем же аккаунтом Google, где лежат книги.
2. Вверху выберите **Select a project → New project**, название «Читалка» → **Create**.
3. **APIs & Services → Library** → найдите **Google Drive API** → **Enable**.
4. **APIs & Services → OAuth consent screen** (экран согласия — окно, которое Google показывает при входе): тип **External**, укажите название и свою почту. В разделе **Test users** (или **Audience → Test users**) добавьте свою почту.
5. **APIs & Services → Credentials → Create credentials → OAuth client ID**:
   - Application type: **Web application**
   - Authorized JavaScript origins: `https://ВАШ-ЛОГИН.github.io` (без `/reader` на конце)
   - **Create** → скопируйте **Client ID**.
6. Откройте читалку → значок настроек → вставьте Client ID → «Сохранить ключ» → «Войти через Google».
   Google покажет «Приложение не проверено» — это нормально, приложение ваше: «Дополнительно» → «Перейти».
7. Выберите папку с книгами. Подпапки первого уровня станут категориями, книги прямо в корне попадут в «Без категории».

## 3. Установить на телефон или планшет

1. **iPhone/iPad:** откройте адрес в Safari → «Поделиться» → «На экран „Домой“».
2. **Android:** откройте адрес в Chrome → меню ⋮ → «Установить приложение».

Важно для iPhone/iPad: пользуйтесь читалкой с иконки на экране «Домой». Тогда система не будет удалять скачанные книги.

## Как это устроено

1. Приложение только читает файлы на Диске и ничего в них не меняет.
2. Заметки, комментарии, рисунки, теги и место чтения сохраняются на устройстве и в скрытой служебной папке приложения на вашем Диске. Так они одинаковы на телефоне и планшете.
3. Вход Google действует около часа. Когда он истечёт, нажмите кнопку синхронизации (две стрелки): приложение попросит войти снова. Точка на этой кнопке означает, что есть несинхронизированные изменения.
4. DjVu пока не поддерживается: такие книги можно сконвертировать в PDF.
